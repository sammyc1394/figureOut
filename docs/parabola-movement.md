# 포물선 이동 명령 P

`P(VX, VY, G)`는 최초 위치에서 도형을 위로 던졌다가 아래로 떨어뜨린다.

- `VX`: 좌우 초기 속도. 양수는 오른쪽, 음수는 왼쪽.
- `VY`: 위쪽 초기 속도. 0보다 커야 한다.
- `G`: 아래쪽 중력 가속도. 0보다 커야 한다.
- 속도는 시트 좌표 단위/초, 가속도는 시트 좌표 단위/초²이다.
- 최초 위치도 기존 좌표 칸에 입력한다. 화면 아래에서 시작하려면 Y를 `-490` 정도로 설정한다.
- `Wait 0.3` 등을 앞에 붙여 도형마다 발사 시점을 다르게 할 수 있다.
- 일시정지 중에는 발사 대기와 궤적의 시간이 정지한다.
- 하강 중 도형 전체가 화면 아래로 나가면 제거된다. 일반 도형을 놓치면 3초 차감하고, 금지 도형은 차감 없이 정리한다.
- 폭탄은 `Rectangle 50:50 (-1)`처럼 기존 금지 도형을 사용한다. 공격 칸이 비어 있으면 접촉/슬라이스 패널티는 기존 기본값인 10초다.

예: `Rectangle 64:64 (1)`, 위치 `(-95, -490)`, 이동 `P(22, 840, 680)`.

Stage 5 M6는 60초 제한, 일반 도형 28개와 폭탄 9개, 8개 묶음으로 구성한다. 묶음 사이의 `Wait 0`은 앞 묶음과 사각형 조각 애니메이션이 정리된 뒤 다음 묶음을 시작한다. 다른 미션의 기존 이동 명령은 변경하지 않는다.

## 데이터와 소스의 전달 범위

- 이 문서의 Stage 5 M6 구성 수치는 해당 모드 작성 당시 기록이다. 현재 미션 구성의 원본은 Google Sheet이며 Git에는 시트 행을 저장하지 않는다.
- 동일한 P 명령은 Circle에도 적용되므로 Stage 6 M3의 Circle 변형에서도 사용할 수 있다. Circle의 공격 방식은 기존 탭이고 Rectangle은 슬라이스이다.
- Stage 6 M4의 Circle3 금지 도형 배치·간격과 시트 행 높이는 시트 데이터/서식이며 이번 Git 전달에서 다시 수정하거나 검증하지 않았다.
- 폐기 요청된 낙하 방어·Simon 기억 모드는 이번 소스 전달에 복원하지 않는다.

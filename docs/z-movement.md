# Z 이동 명령

- `Z(X, Y, 속도)`: 기존 고정 속도 이동.
- `Z(X, Y, 목표속도, 가속시간)`: 속도 0에서 시작해 지정 시간 동안 속도를 선형으로 증가시키고, 이후 목표 속도로 이동한다.
- 예: `Z(160, 0, 200, 4)`는 (160, 0)으로 향하며 4초에 걸쳐 0→200으로 가속한다. 목적지에 먼저 도착하면 가속 도중에도 정확히 멈춘다.
- 가속시간 0은 고정 속도 이동과 같다. 시간은 초 단위이며 소수를 사용할 수 있다.
- `Wait`, `Wait RND`, `Back`, `Repeat`, 일시정지와 함께 사용할 수 있다. 각 이동 구간과 되돌아가는 구간은 속도 0에서 다시 가속한다.
- 이동 속도와 거리는 기존 Z의 가상 플레이 영역 단위를 따른다.
- 4개 인자의 의미는 이제 X, Y, 목표속도, 가속시간이다. 이전 코드의 X, Y, 그리기 우선순위, 속도 해석은 사용하지 않는다. 그리기 순서는 기존 위치 칸의 `Top_` / `Bottom_`을 사용한다.
